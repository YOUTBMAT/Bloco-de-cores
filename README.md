## 📌 Sobre o Projeto

O **Bloco de Cores** é uma aplicação interativa desenvolvida para explorar conceitos de **computação gráfica, mapeamento de coordenadas e estados de interface**. 

O projeto consiste em uma tela dinâmica onde o usuário interage diretamente com elementos visuais (botões) posicionados estrategicamente para modificar as propriedades do ambiente, renderizar textos na tela e alterar a cor do plano de fundo em tempo real.

### 🕹️ Funcionalidades e Mecânicas:
- **Painel Central de Controle:** Um botão centralizado responsável por redefinir e limpar o estado atual da tela.
- **Seletor de Cores Dinâmico:** Três botões posicionados na parte inferior da interface, cada um responsável por alternar o plano de fundo (`background`) para uma paleta de cor específica.
- **Exibição de Texto/Lore:** Manipulação de strings e fontes para renderizar textos informativos na tela conforme as interações acontecem.
- **Lógica de Colisão de Clique:** Implementação matemática de detecção de clique do mouse baseada nas coordenadas `(x, y)` dos botões retangulares.

---

## 📐 Conceitos Lógicos Aplicados

No desenvolvimento deste projeto, foram colocados em prática pilares essenciais da programação gráfica e lógica algorítmica:

*   **Matriz de Pixels e Coordenadas:** Renderização geométrica precisa utilizando planos cartesianos para desenhar e alinhar os botões.
*   **Estruturas de Decisão (`if/else`):** Validação em tempo real para verificar se o clique do mouse ocorreu dentro do escopo de largura (`width`) e altura (`height`) de um botão específico.
*   **Gerenciamento de Estados:** Controle de variáveis que determinam quando o texto de *lore* deve aparecer ou sumir e qual cor deve dominar o fundo.
